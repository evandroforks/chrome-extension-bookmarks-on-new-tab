# Implementation plans

`active/` holds planned, in-progress, blocked, and otherwise unresolved work.
`completed/` holds plans whose validation and selected reviews have passed. Move
the same file from `active/` to `completed/` when closing a plan; do not retain a
duplicate. Name each plan with a concise lowercase hyphenated task slug.

These plans are temporary execution guidance. Durable design decisions belong in
architecture records when the repository adopts them. The default ignore rules
keep plans and discussion briefs in this local checkout across lifecycle moves;
they are not delivered to other clones. This README and the ignore rules are
shareable.
